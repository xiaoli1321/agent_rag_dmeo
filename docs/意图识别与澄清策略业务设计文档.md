# 智能客服意图识别与追问策略业务设计文档

> **文档性质**: 业务与产品设计说明书  
> **适用对象**: 产品经理 (PM)、业务运营人员、客服主管、架构师  
> **设计目标**: 提升客服系统意图识别准确率，实现多轮对话精准追问，降低误答率与人工介入成本。

---

## 1. 业务背景与核心痛点

在传统的 AI 客服系统中，经常遇到以下 **3 大核心业务痛点**：

1. **用户表达过于笼统（如“坏了”、“用不了”）**：
   - 传统的问答系统往往盲目去知识库里乱搜，导致客服给出一个完全不匹配的回答（例如用户其实是蓝牙连不上，系统却回答了传感器脱落）。
2. **多轮对话产品型号混淆（“串话”问题）**：
   - 用户第一句问“GS3 蓝牙连不上”，第二句改问“硅基手表怎么样”，传统的系统容易把两个产品混在一起，导致检索出的内容张冠李戴。
3. **缺少关键信息时死板回答**：
   - 用户问“这设备防水吗？”，在没说具体产品型号的情况下，系统直接给出了某一个产品的回答，造成用户误解。

---

## 2. 核心业务能力

为了解决上述痛点，系统构建了 **“智能感知 + 业务策略把关”** 的双层服务能力：

```
[用户输入] ➔ 【1. 语义智能理解】 ➔ 【2. 业务规则把关与校验】 ➔ 【3. 智能服务路由】
                  (读懂表达)              (检查槽位/过滤模糊词)         (排障 / 追问 / 人工)
```

### 能力 1：智能意图分类与诉求识别
系统能够自动将用户的自然语言表达精准归类为以下 **5 大业务意图**：
- 📘 **产品咨询**：询问设备功能、规格、兼容性、防水等级、佩戴原理等（如：“GS3 支持防水吗？”）。
- 🛠️ **使用问题**：已在使用设备，遇到连接失败、读数异常、告警或佩戴脱落等故障（如：“蓝牙一直连不上”）。
- 🎧 **售后诉求**：涉及退款、换货、发货进度或投诉转人工（如：“我要退货”、“马上转人工”）。
- ❤️ **情绪安抚**：用户表达愤怒、不满或焦虑时，优先进行温暖共情，再引导解决问题。
- 💬 **闲聊问候**：日常打招呼或问候。

### 能力 2：智能槽位追问与补充（每轮追问 1 个点）
当用户表达缺少关键信息时，系统**绝不盲目猜测**，而是会自动发起智能追问：
- **精细化单点追问**：每轮对话只追问 **1 个**最关键的缺失信息，避免一次性问多个问题导致用户烦躁。
- **一键快捷按钮**：追问的同时，向前端吐出可点击的推荐选项（如：`[GS3, GS1, ECO, 硅基手表]`），用户点击即可完成补充。

### 能力 3：业务风控与自动拦截
- 🚑 **医疗风险拦截**：当检测到“昏迷”、“大量出血”等急救或医疗风险表达时，自动进行安全拦截，避免法律与安全风险。
- 🛡️ **模糊词自动澄清**：遇到“坏了”、“搞不定”等抽象词，自动拦截并引导用户选择具体现象。
- 🚨 **追问超限自动切人工**：连续追问 2 轮仍未收集齐全时，系统自动无缝切入人工客服，并为坐席自动生成沟通摘要。

## 3. 业务配置与运营管理 (运营可控)

业务人员与运营无需编写代码，只需在业务配置文件中进行简单修改，即可实时控制 AI 客服的反应：

| 配置项 | 业务含义说明 | 示例 |
| :--- | :--- | :--- |
| **必填槽位 (`required_slots`)** | 处理该意图前必须收集齐全的信息。 | 如：`使用问题` 必须包含 `[目标产品型号, 具体故障现象]` |
| **追问顺序 (`clarification_order`)** | 信息缺失时的优先追问顺序。 | 如：先追问 `目标产品型号`，下一轮再追问 `具体故障现象` |
| **追问话术与选项 (`question & options`)** | 系统向用户发起的追问文本及快捷按钮。 | 话术：*“请问你咨询的是哪款产品或设备型号？（我们主要有 GS1、ECO、GS3）”*<br/>选项：`["GS1", "ECO", "GS3"]` |
| **模糊词列表 (`vague_values`)** | 需要自动拦截并澄清的抽象词。 | `["坏了", "不行", "有问题", "用不了", "罢工了"]` |
| **直通人工开关 (`direct_handoff`)** | 是否跳过机器回答，直接转交人工。 | 如：`售后诉求` 默认设为 `true` 直通人工 |

## 4. 典型业务场景流转图解

### 场景一：表达模糊（“GS3 坏了”） ➔ 触发精准排障追问

```
[用户]: "我的 GS3 坏了"
   │
   ▼
[系统识别]: 识别到产品为 GS3，但故障描述 "坏了" 属于模糊词！
   │
   ▼
[智能追问]: "GS3 具体出现了什么问题或表现？"
           提供选项: [ 无法连接 | 读数异常 | 传感器脱落 | 其他问题 ]
   │
   ▼
[用户点击]: "无法连接"
   │
   ▼
[精准解答]: 调取《GS3 蓝牙连接故障排障指南》进行精确解答！
```

---

### 场景二：泛指查询（“公司有哪些产品？”） ➔ 智能输出全系概览

```
[用户]: "公司有哪些产品？"
   │
   ▼
[系统识别]: 智能识别为“全局概览查询”，自动豁免产品型号追问。
   │
   ▼
[全量解答]: 输出包含 GS3、GS1、ECO、硅基手表在内的完整产品线介绍与对比！
```

---

### 场景三：表达愤怒 / 明确要退款 ➔ 绿色通道切人工

```
[用户]: "你们产品太垃圾了，根本连不上，我要退款转人工！"
   │
   ▼
[系统识别]: 识别到情绪为 [愤怒]，诉求为 [售后退款]。
   │
   ▼
[优先安抚]: "非常理解您遇到设备连不上时的焦虑与气愤，换作是我也会非常着急..."
   │
   ▼
[切人工通道]: 自动生成“GS3蓝牙连不上/用户愤怒要求退款”摘要工单，直通售后坐席！
```

## 5. 业务收益与效果

1. **解决答非所问**：通过模糊词拦截与槽位追问，将 RAG 知识库检索的答非所问率降低 80% 以上。
2. **提升服务体验**：快捷点击按钮降低了用户打字门槛，多轮产品切换不再发生串话混淆。
3. **运营高效灵活**：话术、模糊词、追问顺序全配置化，业务运营可随随时调整，无需等待程序员发版。
